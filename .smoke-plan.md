# Смок-прогон — стек #31–#54 (интеграция `integration/ai-stack`)

Полный протокол ручного прогона по стеку фич AI-модуля. Каждый кейс —
действие + **Ожидаемый результат** для сверки. Полный e2e-протокол —
`tests/foundry-e2e/smoke/README.md`.

## Подготовка мира (один раз перед прогоном)

- **Деплой модуля:** содержимое `integration/ai-stack` в
  `Data/modules/only-war-ai` (scripts/languages/styles/templates/module.json).
- **Сцена:** Smoke Arena 40×30; Combat staged — Alpha 2/3/4, Beta 1–3,
  Spec 1/2, Hold Gunner + аколиты.
- **Файртим Alpha** (нужен для SQ-кейсов) — в консоли GM:
  ```js
  const alpha = game.combat.combatants.filter(c => c.name.startsWith("Alpha"));
  const leader = alpha[0];
  for (const c of alpha) await c.setFlag("only-war-ai", "fireteam",
    { teamId: "alpha", leaderId: leader.id, character: "disciplined" });
  ```
- **Флеймер** — выдать одному Alpha (напр. Alpha 3) предмет-оружие:
  `{class:"ranged", range:~8, special:"spray"}` — для OW54-2.
- **Гренадёр** — выдать одному Spec (напр. Spec 2) оружие с
  `blastRadius:>0` — для OW54-3.
- **Пресеты/черты** — одному Beta выставить `personality:["cowardly"]`,
  одному Alpha `personality:["fanatic"]` — для MOR/PERS-кейсов.
- **Настройки:** `masterEnabled` on, `executionMode:"preview"`,
  `diagnosticsEnabled` on, `aiBarks` on, `aiCaptureContext` on,
  `aiTraceVerbose:"compact"`, `previewTimeoutSeconds:0`,
  `turnPacingMs:800`, `manualOverrideGrace` off, `moraleDesperateRatio` 2.

**Старт:** Begin Combat.

## История прогонов (найденные баги)

- **К1/LOS:** `_fallbackTargets` помечал всех врагов `canAttack:true` без
  LOS-гейта → атака сквозь стены. Фикс dbda017: LOS-гейт в фолбэке.
- **К5:** `run.spent` не считал ручной перенос → реплан отматывал ход.
  Фикс dbda017: дрейф позиции → `spent.movement`.
- **OW-собственный токен (#54):** self в `_blastTokens` ветировал прицел
  шаблона → молчала деградация в bearing. Фикс 052bb07.
- **Replay-divergence (интеграция):** `actor.items` не доезжали в захват
  → `ev`=0 на реплее. Фикс 8a9f1f5: item-статистика в snapshot +
  восстановление в `replay-helpers`.
